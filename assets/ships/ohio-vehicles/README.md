# Ohio flying vehicles

Kenney Car Kit 3.1, CC0. Derived from the selected GLBs in ../../environments/kenney-car-kit, whose license and provenance apply. Built by tools/bake-ohio-flight-vehicles.py via the roadside catalog. Flight coordinates: +Y forward, +Z up, max dimension 16 metres; headlights carry two gun mounts, rear corners two engine mounts. Palette texture stores the baked material colors. Mission-only models are excluded from generic mixed fleets.
