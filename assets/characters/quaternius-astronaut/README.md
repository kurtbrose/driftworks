# Astronaut by Quaternius

User-supplied GLB acquired 2026-10-16, preserved unchanged in `original/`. [Original model listing](https://poly.pizza/m/3hC2i0CTuO) credits Quaternius and identifies the license as [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The download did not include a separate license file; this listing is the license evidence. See `provenance.json` for source URL, acquisition details and SHA-256.

The viewer plays the animations embedded in the model. Universal Animation Library clips are separate and require retargeting before use with this rig. Source scale, materials and animation tracks are unmodified.

The viewer supports reversible suit palettes through `experiments/character-paints.js`: independent suit and trim colors, four presets, and an Original option. Suit paint targets `SciFi_Light` and the darker `SciFi_Main` panels (20% of the chosen linear color); trim targets `SciFi_Light_Accent`. `SciFi_MainDark`, `Grey`, roughness, metallic response, and animation tracks retain their source values. No recolored copies of the GLB are generated. The same palette helper can be reused when displaying this model elsewhere.
