# Universal Animation Library 2 - Standard

Creator: [Quaternius](https://quaternius.com/packs/universalanimationlibrary2.html). License: CC0-1.0; see `original/License.txt`. Acquired 2026-10-16 from a user-supplied ZIP.

The original ZIP was removed after extraction. `original/` contains all formats, setup images, textures and documentation with original relative paths. `provenance.json` records the original archive name and SHA-256 for the archive and every extracted file.

Open `../../../experiments/characters.html` through the local HTTP server to inspect every glTF/GLB with source materials, skinning and clip playback. All included FBX, OBJ and Blender files remain available for authoring. No geometry, scale, axes or animation tracks have been converted.

The animation libraries have their own mannequin rig. `_RM` files contain baked root motion; other files disable it. Retargeting to other character rigs is a separate authoring step, not automatic. The female mannequin is a static retargeting target; see its original README.
