# Image generation frontal portrait trial

Four independent edits using the built-in image generation tool. Originals remain
in `../../inputs/`; each output keeps the source's portrait ID. No game integration
or runtime dependency was added. These are manual generative edits, not a
deterministic converter. Review each result before using it in a larger set.

Source IDs: p001-006, p001-057, p006-042, p006-064. Source provenance and attribution:
`../../manifest.json` (Human Faces Dataset Generated by Stable Diffusion,
deepintelligence, 2025; CC-BY-4.0 as recorded there). Outputs are modified versions.

## Exact shared prompt

Edit target: the single synthetic adult portrait supplied. Create one photorealistic passport-style head-and-shoulders portrait of this same approximate person, facing EXACTLY straight toward the camera. Head upright, zero yaw or tilt, shoulders square, both eyes looking directly at the viewer, neutral closed-mouth expression, centered symmetrical framing. Retain approximate age, hair, skin tone, facial hair, glasses and visible clothing; exact identity/detail preservation is not essential. Use even soft frontal illumination. Include the complete crown of hair with a little clear margin above and sides, shoulders cropped at bottom. Remove the entire scene/background and generate genuine transparent alpha around the person, including hair edges. Single square portrait, no text, no border, no collage.

Tool option: `transparent_background: true`, one source image per call.

All four PNGs are 1254 by 1254 and contain real alpha transparency (sampled
alpha includes zero and near/full opacity). The p001-057 output's sampled maximum
alpha is 253, so its subject is slightly translucent; inspect compositing before
production use. Files were copied unchanged from tool outputs.

## Review

All four outputs visually face forward and remove the original scene. Head scale
and eye height are similar but not precisely standardized. Facial and clothing
details can change, as permitted for this experiment. Hair-edge quality should
be reviewed against the eventual display background.
