# Procedural portrait research — 2026-10-19

The experiment has run on 24 curated synthetic adult portraits. **No candidate yet
meets the intended WC2-inspired artwork standard.** Several retain recognizable
identity, but textures and tonal boundaries still read as processed photographs.
Preserve baseline, contour, and revised structure candidates for human review.

## Inputs and limitations

The original gallery was unreachable. The replacement is
[deepInteligence/25K-synthesized-face](https://github.com/deepInteligence/25K-synthesized-face),
attributed to deepintelligence, *Human Faces Dataset Generated by Stable Diffusion*
(2025). Its README states CC BY 4.0. Outputs are procedural derivatives. WC2
screenshots inform visual goals only. Processing is entirely deterministic 2D;
there are no generative transformations or individual portrait retouches.

Two 32 MiB ranged downloads from the roughly 9.5 GB split Drive archive yielded
180 intact, CRC-verified PNGs. Visual curation retained 24 adult head-and-shoulders
portraits with open eyes and calm expressions, including glasses, facial hair,
wrinkles, dark hair, uneven lighting and varied skin tones. Source hashes, paths,
tags and acquisition provenance are preserved. Originals remain local and ignored.

This archive-order convenience sample is not a demographic benchmark. Pose is
mostly frontal or slight three-quarter, but head size and backgrounds are still
insufficiently standardized: p001-012 and p001-079 allocate fewer pixels to faces.
Every method sees exactly the same crop per face. The manifest records an 18/6
exploration/held-out split; review is exploratory, not blinded validation.

## Comparison and failures

The first sweep crosses four families, 16/32 colors, 64/96 working grids, ordered
dither off/on, and 128/256 output. The revision adds eight structure settings at
both sizes: **1,920 rendered portraits**, four formats, **7,680 measured assets**,
60 sweep sheets and 16 comparison sheets. Useful intermediates and both scripts
are preserved. Visual review used compact matched-setting sheets, initial
comparison sheets and parameter sheets. The full sweep is preserved, not claimed
exhaustively rated. `review.csv` remains an unscored human review form.

| Family | What worked | What failed |
| --- | --- | --- |
| Baseline | Recognizable geometry; glasses legible at grid 96 | Skin speckle, fragmented shadows, photographic backgrounds |
| Median clusters | Cleaner skin planes and broad shapes | Pupils, glasses and lips merge, notably p001-079/p006-018 |
| Contour planes | More visible lips and boundaries than aggressive smoothing | Green/purple tonal artifacts; false background contours |
| Feature/multiscale | Less skin noise; broad hair mass retained | Eyes too soft; fixed feature priors fail with different head scales |
| Revised structure | Better dark detail and glasses on p001-005/p001-079/p006-060 | More source texture returns; distant faces remain weak |

The revision addresses observed detail loss by protecting local dark residuals and
gradients over a smoothed base, independent of assumed eye locations. Dither is
restricted to transitions and suppressed on flat planes and dark marks. It improves
readability, but does not create designed facial shading. No pupils are invented;
no mirroring conceals asymmetric sampling.

Grid 64 sacrifices small facial marks. Grid 96 retains more information, though
nearest enlargement to 128 produces unequal pixel widths. 16 colors more often
merges facial features; 32 is a safer review candidate. Ordered dither visibly
adds skin texture, particularly with 16 colors. Preserve no-dither candidates.
Hair silhouettes mostly remain, while strands and dark-on-dark boundaries merge.
Nose planes and lip separation remain lighting/palette-sensitive. No numerical
identity metric was used as a substitute for visual inspection.

## Actual compressed bytes

Median bytes per asset, pooling 40 settings and 24 faces: 960 samples per size and
format. These are measured sweep results, not a production budget forecast.

| Output | RGB PNG | Indexed PNG | Lossless WebP | WebP quality 85 |
| --- | ---: | ---: | ---: | ---: |
| 128×128 | 5,803 | 3,188.5 | 2,498 | 3,773 |
| 256×256 | 7,109.5 | 3,901 | 3,068 | 5,564 |

All PNG/lossless WebP round trips are pixel-exact. Indexed PNG is a supplemental
export from preserved RGB outputs, verified pixel-exact for every file. Lossy
WebP does not reliably save space here and may introduce edge ringing. Results
depend on these images and codec settings. Comparing WebP only with RGB PNG would
overstate its advantage. AVIF and codec timings were not measured. Each run has
per-file `sizes.csv` and `indexed-sizes.csv`; `results/size-summary.csv` contains
per-family medians, ranges, counts and totals.

## Verification

Python tests cover all 80 algorithm/resolution combinations for determinism,
palette limits, dimensions and lossless decoding. An end-to-end diagnostic chart
checks manifest hashes, sheet generation and exported bytes. Diagnostic charts
are software tests, not research faces. Repository `npm run check` passed,
including type checks, asset versions, all 330 browser-native tests and additional
checks. No gameplay systems or runtime dependencies changed.

## Next experiment and stopping point

Further progress needs artistic direction on facial-plane simplification:
restrained illustrated realism versus strong graphic/comic shading. First improve
head-scale consistency using reproducible 2D landmark alignment; compare a shared
curated skin/hair palette against these per-face palettes. Review alignment on
glasses, caps and darker skin. Background removal is also unsolved.

After selecting a still direction, test localized 2D eye/mouth masks, affine warps
and procedural shapes for closed/half/open eyelids and closed/A/E/O mouths.
Freeze palette, lighting and pixels outside masks across frames. Review identity
drift, glasses seams and shimmer in a fixed sequence. Warping alone cannot recover
unseen eyelids or teeth; that requires a separate procedural shape-design study.
Compare sprite bytes with animated lossless WebP. This tool produces stills only.

This is a meaningful comparison, not a successful production portrait pipeline.
Human preference between preserved candidates is the appropriate next decision.
